سياسة الخصوصية

Ledgererp — منصة الفواتير والضمان الآمن Pi Network

آخر تحديث: سبتمبر 2025

🔒 Ledgererp يلتزم بحماية خصوصيتك. نحن لا نبيع أو نشارك بياناتك الشخصية مع أطراف ثالثة لأغراض تسويقية.

1. المعلومات التي نجمعها

عند استخدامك لتطبيق Ledgererp، قد نجمع المعلومات التالية:

  • معرّف Pi (UID): يتم الحصول عليه تلقائياً عند تسجيل الدخول عبر Pi Network للمصادقة وربط حسابك.
  • اسم المستخدم Pi: لعرضه في ملفك الشخصي داخل التطبيق.
  • بيانات المتجر: اسم المتجر، الوصف، والصورة التي تقدمها طوعاً.
  • بيانات الفواتير: معلومات الفواتير والمنتجات التي تنشئها كجزء من خدمة إدارة الفواتير.
  • بيانات المعاملات: معرّفات معاملات Pi (payment IDs) لمعالجة المدفوعات وإدارة الضمان.

2. كيف نستخدم المعلومات

نستخدم المعلومات المجمعة للأغراض التالية:

  • المصادقة على هويتك عبر Pi Network وتوفير خدمة إدارة الفواتير.
  • معالجة مدفوعات Pi وإدارة حسابات الضمان بين البائعين والمشترين.
  • إرسال إشعارات حول حالة الفواتير والمعاملات.
  • تحسين أداء التطبيق وتجربة المستخدم.
  • الامتثال لمتطلبات Pi Network وسياسات المطورين.

3. حماية البيانات

نتخذ إجراءات أمنية مناسبة لحماية بياناتك، تشمل:

  • تشفير الاتصالات عبر HTTPS/TLS.
  • تخزين بيانات حساسة بشكل مشفر.
  • تقييد الوصول إلى البيانات على مبدأ الحاجة الأقلية.
  • مراجعة دورية لإجراءات الأمان.

4. مشاركة البيانات

لا نشارك بياناتك الشخصية مع أطراف ثالثة إلا في الحالات التالية:

  • مع Pi Network لمعالجة المدفوعات والمصادقة (وفق شروط Pi Network).
  • وفقاً لطلب قانوني أو أمر قضائي.
  • لحماية حقوقنا أو سلامة المستخدمين الآخرين.

5. معاملات Pi والضمان

Ledgererp يعمل كوسيط ضمان لمعاملات Pi بين البائعين والمشترين:

  • أموال الضمان تُحفظ على شبكة Pi Blockchain ولا يمكن الوصول إليها من قبل التطبيق.
  • إطلاق الأموال يتم فقط بعد تأكيد التسليم من قبل المشتري.
  • في حالة النزاع، يتم اتباع إجراءات حل النزاع المحددة.
  • رسوم الضمان (2%) تُضاف إلى إجمالي الفاتورة.

6. حقوقك

لديك الحق في:

  • الوصول إلى بياناتك الشخصية المخزنة.
  • طلب تصحيح أي بيانات غير دقيقة.
  • طلب حذف حسابك وبياناتك (مع مراعاة متطلبات حفظ السجلات).
  • سحب موافقتك على معالجة البيانات في أي وقت.

7. ملفات تعريف الارتباط (Cookies)

نستخدم ملفات تعريف الارتباط لتخزين تفضيلات الجلسة وحالة المصادقة فقط. لا نستخدم ملفات تعريف ارتباط للتتبع أو الإعلانات.

8. تغييرات السياسة

قد نُحدّث هذه السياسة من وقت لآخر. سنعلمك بأي تغييرات جوهرية عبر التطبيق. استمرارك في استخدام التطبيق بعد التحديث يعني موافقتك على السياسة المُعدّلة.
